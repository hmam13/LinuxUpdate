=========================================
      ¡BIENVENIDO A TU ACTUALIZADOR!
=========================================

Este programa es como un "control remoto" mágico que sirve para que tu distribución Linux esté siempre limpia, rápida y con los juguetes (programas) más nuevos.

Aquí te explico cómo usarlo de forma muy fácil:

1. ¿QUÉ NECESITAS ANTES DE EMPEZAR?
----------------------------------
* Una computadora con Linux (Kali, Parrot o Arch).
* Tener instalado Python y Tkinter (que es el lenguaje en el que habla este robot).
* Permisos de "Súper Usuario" (Sudo). Esto es como tener la llave maestra de la casa para poder limpiar todas las habitaciones.

2. ¿CÓMO SE ENCIENDE?
---------------------
Para despertar al robot, abre tu terminal (la pantalla negra) y escribe:

   sudo python3 LinuxUpdate.py

3. ¿CÓMO SE USA EL PANEL?
-------------------------
Cuando se abra la ventanita gris, verás varias opciones:

* BOTONES DE ACTUALIZAR: Solo debes presionar el botón que dice el nombre de tu sistema. Si usas Kali, dale al de Kali. ¡No presiones los otros para no confundir a la computadora!
* BOTÓN DE AYUDA: Si te sientes perdido, presiónalo y te dará un consejo rápido.
* BOTÓN CERRAR: Úsalo cuando ya hayas terminado de jugar o trabajar para que el programa se vaya a dormir.

4. ¿QUÉ PASA DESPUÉS DE DAR CLIC?
---------------------------------
El programa te hará una pregunta para estar seguro. Si dices que "Sí":
1. La ventanita se cerrará.
2. Verás letras de colores en la terminal.
3. El AZUL significa que está trabajando.
4. El VERDE significa que ¡todo salió perfecto!
5. El ROJO significa que algo le dolió a la computadora y se detuvo.

5. CONSEJOS DE AMIGO
--------------------
* No apagues la computadora mientras veas las letras de colores moviéndose.
* Si te pide tu contraseña, escríbela (aunque no veas que aparecen bolitas o estrellas, la computadora sí te está escuchando).
* Si estas usando "Arch Linux", se encuentra un instalador para Tkinter, de la misma forma ejecutalo en la terminal, para poder usar bien el actualizador.
